# pymas

pymas is a lightweight Python statistics library for common statistical calculations.

## Features
Descriptive statistics, dispersion, percentiles, frequency analysis, correlation and regression, probability, distributions, hypothesis testing, confidence intervals, random sampling, and data utilities.

## Example
```python
from pymas.statistics import mean, median, standard_deviation

data = [10, 20, 30, 40, 50]
print(mean(data))
print(median(data))
print(standard_deviation(data))
```
